# Editing Your Website

For the default no-code workflow, open `editor/index.html` or `OPEN EDITOR.cmd` and follow the [Portfolio Studio guide](PORTABLE_EDITOR.md).

Use **Save backup** for an editable copy and **Download website** for a public ZIP. They serve different purposes: backups include drafts, while website downloads exclude them.

For the optional online Decap CMS at `/admin/`, see the [CMS guide](CMS_GUIDE.md). CMS changes and browser editor changes are separate and do not synchronize automatically.
